# Voldiq 0.2.0 · Skyline

Explore storage as a proportional treemap or an architectural city. Skyline elevates the same measured rectangles, keeping your folder, selection, filters and colors when you switch views.

- Canvas 2D isometric geometry with verified occlusion and facade selection, cursor-centered zoom, pan, Fit and visual relief.
- Modification age, descendant file count and relative depth heights. Directory ages show known descendant coverage. Unknown dates and allocation stay explicit.
- Shared file-category colors, sequential size/age scales, clipped shadows, quiet facade windows and rooftop detail. Detail reduces as blocks get smaller.
- A compact map toolbar, warmer light surfaces, synchronized keyboard-accessible file list and dismissible responsive inspector. Dark appearance remains available.
- Cleanup review uses the existing native preview and confirmation. Selecting a folder never authorizes its contents for deletion.

No new runtime dependencies, graphics engine or server. The Windows x64 installer includes the offline WebView2 runtime. Application and installer remain unsigned.

Verification includes 20 frontend tests, 10 Rust tests, strict Clippy, a production build, ray-based geometry/shadow checks, million-file in-memory query benchmarks and native Windows WebView2 interaction checks. Captures cover laptop/desktop viewports and emulated pixel ratios from 1 to 2. Native operating-system scaling changes, screen-reader acceptance and clean-machine installation were not tested for this release.

See the [Skyline implementation and verification notes](https://github.com/Hakaelll/Voldiq/blob/main/docs/SKYLINE.md) and [native captures and measurements](https://github.com/Hakaelll/Voldiq/tree/main/benchmarks/disk-city).
