# Voldiq 0.1.0

The first Windows release of Voldiq brings local storage exploration, verified duplicate detection and reviewed cleanup into one desktop application.

## Download

Install **Voldiq_0.1.0_x64-setup.exe** on Windows 10 or 11 x64. The current-user installer includes the offline Microsoft WebView2 runtime. No account, internet connection or development tools are required to use the application.

Compare the installer's SHA-256 with the attached **SHA256SUMS.txt**. The application and installer are unsigned.

## Included

- Live drive and folder analysis with measured logical and unique allocated sizes.
- An interactive treemap, folder details, virtual file lists and large-file rankings.
- Native indexed search with Ctrl+K, filters, sorting and keyboard navigation.
- Complete BLAKE3 duplicate verification with a persistent validated hash cache.
- Explicit cleanup previews, confirmed recycling and restoration of compatible recorded items.
- Separate typed confirmation for irreversible permanent removal.
- Developer storage analysis, supported package-manager caches and local Docker storage inspection.
- Local SQLite snapshots with growth and file-change comparisons across restarts.
- Light and dark themes, hover navigation, reduced motion and persisted scan preferences.

## Verification

The final source gate covers Rust formatting, Svelte diagnostics, eight retained tests, the production frontend build and strict workspace Clippy. Distribution checks execute the native embedded-asset probe and verify architecture, version, artwork, offline runtime and installer configuration. The project owner accepted the outstanding manual checks before delivery.

Performance measurements apply to their documented hardware and workloads. Moving files to the Recycle Bin does not immediately free their occupied space. Restoration never overwrites an existing file; permanent removal has no undo. Some filesystem, browser-cache and tool-configuration cases are deliberately unsupported. See the repository documentation for scope and guarantees.
